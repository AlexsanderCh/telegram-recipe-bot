# Telegram-бот рецептов

Telegram-бот на Python и aiogram 3 для поиска рецептов через бесплатный
[TheMealDB API](https://www.themealdb.com/api.php). Пользовательские рецепты и
оценки хранятся локально в базе SQLite.

## Возможности

- поиск рецептов по названию;
- вывод фотографии, категории, кухни, ингредиентов и инструкции;
- рейтинг рецептов от 1 до 5 звёзд;
- автоматическое сохранение оценённых рецептов в избранное;
- отдельное избранное для каждого пользователя;
- сортировка избранных рецептов по рейтингу;
- ссылки на видеорецепты, если они доступны в TheMealDB.

## Технологии

- Python;
- aiogram 3;
- aiohttp;
- TheMealDB API;
- SQLite;
- python-dotenv.

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта.
2. Создайте и активируйте виртуальное окружение:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```

3. Установите зависимости:

   ```powershell
   pip install -r requirements.txt
   ```

4. Скопируйте `.env.example` в `.env` и укажите токен бота:

   ```dotenv
   BOT_TOKEN=your_telegram_bot_token
   ```

5. Запустите бота:

   ```powershell
   python bot.py
   ```

База `recipes.db` создаётся автоматически при первом запуске. Файл `.env`,
виртуальное окружение, Python-кэш и локальные базы данных исключены из Git.
